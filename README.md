# 岩芯样本切片实验室

运行：

```bash
npm start
```

访问`http://localhost:3025`。支持样本创建、切片任务、步骤记录、交付统计和任务结算。

## 任务结算

- 样本建档时登记**委托单位**和**加急**标记。
- 每张切片按已记录的取样、切割、研磨、染色步骤计费（观察不计费），同一步骤重复记录只收一次；加急任务在总额上多收三成。
- 所有切片完成（进入观察）后才能结算；步骤补录或更正后重新试算，已结算任务需先撤回（旧账单保留在账单记录里）再重新结算。
- 已结算任务不可再新增切片或补录/更正步骤，撤回账单后即可。

## 业务文件

- `fee-rules.js`：费用规则（步骤单价、加急比例、账单试算）。
- `bill-store.js`：账单存储（`data/bills.json`，撤回只改状态不删除）。
- `page-operations.js`：页面操作接口（费用试算 `GET /api/samples/:id/billing`、结算 `POST /api/samples/:id/settle`、撤回 `POST /api/samples/:id/withdraw`）。
