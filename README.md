# 岩芯样本切片实验室

运行：

```bash
npm start
```

访问`http://localhost:3025`。支持样本创建、切片任务、步骤记录、交付统计和任务结算。

## 结算规则

- 建档时登记**委托单位**和**加急标记**。
- 每张切片按已记录的 取样 / 切割 / 研磨 / 染色 步骤计费（观察不计费），同一步骤重复记录只收一次。
- 加急任务在总额上多收三成。
- 切片全部完成（走到"观察"）才能结算；步骤补录或更正（删除错误日志）后可重新结算。
- 重新结算会先撤回旧账单并留档，旧账单状态为"已撤回"，可在卡片中查看历史。

## 业务文件

- `billing-rules.js`：费用规则（步骤单价、加急比例、按日志报价）。
- `billing-store.js`：账单存储（结算、撤回、历史账单留档）。
- `page.js`：页面操作（单页应用与结算交互）。
- `server.js`：HTTP 服务与路由。

## 结算接口

- `GET /api/bills`：全部账单（新的在前）。
- `POST /api/samples/:id/settle`：结算/重新结算（有未完成切片返回 400）。
- `POST /api/bills/:id/withdraw`：撤回账单。
- `DELETE /api/samples/:sid/slices/:sliceId/logs/:index`：删除误记步骤日志（更正）。
